# Changelog

This project does not yet publish release notes. Until it does, the
[commit history](https://github.com/deepset-ai/haystack-enterprise-sdk/commits/main) and
[releases](https://github.com/deepset-ai/haystack-enterprise-sdk/releases) on GitHub are the record of
what changed.

The SDK is **experimental**: APIs and CLI commands may change without notice.

## Version history

**0.1.0** — first release under the name Haystack Enterprise SDK, published to
[PyPI](https://pypi.org/project/haystack-enterprise-sdk/) on 2026-08-31.

Note the version number restarted at the rename: `deepset-cloud-sdk` had reached `1.7.x`, and
`haystack-enterprise-sdk` begins again at `0.1.0`. They are different packages on different release
lines, so version numbers do not compare across the rename. See
[Migrating from deepset-cloud-sdk](migrating.md).
