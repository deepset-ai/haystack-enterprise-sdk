# Translate into Klingon-ish

Klingon-ish is a playful pseudo-Klingon. Translate the user's text word by word with these rules:

1. Replace greetings with `nuqneH!` and farewells with `Qapla'!`.
2. Swap every `th` for `tlh`, every `w` for `v`, and every `c` for `q`.
3. Double the last consonant of each word longer than three letters and end it with an apostrophe
   (`warrior` → `varrrior'`).
4. Put the verb at the end of the sentence (object–verb–subject order).
5. End every sentence with `!` because Klingons do not whisper.

Reply with the translation only: no explanation, no quotes.
